Héraut Telgamor

Politique de confidentialité

Dernière mise à jour : 31 octobre 2026 · English version below

Qui sommes-nous

Le Héraut Telgamor est un outil personnel de publication, utilisé uniquement par Alaak, illustratrice et autrice de l'univers Telgamor, pour publier son propre travail sur ses propres comptes (YouTube, Instagram, Bluesky, Discord). Il n'est pas proposé au public : personne d'autre ne peut s'y connecter.

Contact : alaak.painting@gmail.com

Données utilisées

Le Héraut n'utilise que les données des comptes d'Alaak, avec son autorisation explicite :

  • YouTube (services API YouTube) : un jeton d'accès autorisant la mise en ligne de vidéos sur sa chaîne, et le nom de cette chaîne pour vérifier la connexion. Les vidéos, titres et descriptions envoyés sont ceux qu'elle a choisis.
  • Instagram (Meta) : un jeton d'accès autorisant la publication de photos sur son compte, ainsi que l'identifiant et le nom de ce compte.
  • Bluesky et Discord : un mot de passe d'application Bluesky et des adresses de webhook Discord, permettant de publier sur ses comptes.

Le Héraut ne collecte aucune donnée sur d'autres personnes, n'utilise ni cookies ni outils de suivi, et n'affiche pas de publicité.

Stockage et partage

Ces informations sont stockées uniquement sur l'ordinateur personnel d'Alaak, dans des fichiers locaux. Elles ne sont ni vendues, ni partagées avec des tiers. Elles ne sont transmises qu'aux plateformes concernées (YouTube, Instagram, Bluesky, Discord), au moment de publier. Pour publier sur Instagram, les images d'une publication sont rendues accessibles quelques minutes, sous une adresse aléatoire, le temps qu'Instagram les télécharge.

Services API YouTube

Le Héraut utilise les services API YouTube. Son utilisation implique l'acceptation des Conditions d'utilisation de YouTube. Les données obtenues via les services API YouTube sont aussi régies par les Règles de confidentialité de Google.

Conservation et suppression

Les jetons sont conservés tant que la connexion est active. Pour retirer l'accès du Héraut à un compte Google à tout moment : page des autorisations du compte Google. L'accès Instagram peut être retiré dans les paramètres Instagram, rubrique « Applications et sites web ». Toute demande de suppression adressée à l'adresse de contact est traitée sous 7 jours : les fichiers locaux contenant les jetons sont alors effacés.

Privacy Policy (English)

Héraut Telgamor is a personal publishing tool used only by Alaak, the illustrator and author of the Telgamor universe, to publish her own work on her own accounts (YouTube, Instagram, Bluesky, Discord). It is not offered to the public and no one else can sign in to it. Contact: alaak.painting@gmail.com.

Data used. Only data from Alaak's own accounts, with her explicit authorization: a YouTube API access token allowing video uploads to her channel, and the channel name to check the connection; an Instagram access token allowing photo publishing on her account, with the account ID and username; a Bluesky app password and Discord webhook URLs. No data about other people is collected. No cookies, tracking or advertising.

Storage and sharing. This information is stored only on Alaak's personal computer, in local files. It is never sold or shared with third parties, and is only sent to the platforms concerned (YouTube, Instagram, Bluesky, Discord) when publishing. For Instagram, the images of a post are made available for a few minutes at a random address so that Instagram can download them.

YouTube API Services. Héraut Telgamor uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Data obtained through YouTube API Services is also subject to the Google Privacy Policy.

Retention and deletion. Tokens are kept while the connection is active. Google access can be revoked at any time on the Google account permissions page; Instagram access in Instagram's "Apps and websites" settings. Deletion requests sent to the contact address are handled within 7 days, by erasing the local files that hold the tokens.
